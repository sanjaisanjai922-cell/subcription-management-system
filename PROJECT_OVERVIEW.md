# Project Overview

## Title
Subscription Billing Management System

## Aim
To develop a Java-based application that manages subscription plans, customer subscriptions, recurring invoices, payment records and billing reports using a MySQL database.

## Objectives
1. Maintain customer account details.
2. Create and manage monthly, quarterly and yearly subscription plans.
3. Allow customers to subscribe to and cancel plans.
4. Generate invoices and track due dates.
5. Record payments and maintain transaction history.
6. Provide billing summaries for administrators and billing staff.

## Users
- Administrator: manages customer accounts and subscription plans and views all billing information.
- Billing Staff: monitors subscriptions, invoices and payments and generates due invoices.
- Customer: views available plans, manages subscriptions and pays invoices in the demo system.

## Technologies
Java 17, Java Swing, JDBC, MySQL, Maven and OpenPDF.
